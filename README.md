# drufiy-project-work-zip-files-

Working repo for the Drufiy website UI redesign project.

## What's here

The `documentation/` folder contains the full planning package for redesigning
the UI of `drufiy.com`, `lear.drufiy.com`, and `prash.drufiy.com`:

- A complete as-is audit of the live site (every page, section, word of copy,
  number, link, form, and integration).
- A target system design / information architecture for the redesign.
- Three concrete new UI directions to choose from for the "entry page" and
  the rest of the site.
- A locked "do not touch" guardrail list (routes, pricing/legal claims, exact
  strings, live forms and integrations).
- A ready-to-paste prompt for an AI coding tool to actually generate the new
  UI without breaking any of the above.
- A QA/acceptance checklist for verifying the result, and a one-page cover
  sheet for your auditor.
- Machine-readable `design-tokens.json` and `content-model.json`.
- `documentation/index.html` — a single-file, printable version of the whole
  package (open in a browser, print to PDF).

Start at `documentation/00-INDEX.md`.
